AI 游戏社区评测分享平台

PC 端 Web · 仅适配桌面浏览器 · 暗色游戏主题 · 三类角色：玩家 / 创作者 / 管理员

主色渐变
评分金 #ffb020

布局：顶部导航 60px + 内容区最大宽度 1200px 居中；卡片圆角 12px；状态用彩色徽标（绿=通过/已发布，黄=审核中/草稿，红=驳回/封禁，蓝=AI/人工复核中）。

页面站点地图（12 个页面）
① 首页 /index.html
Hero 推荐位、热门游戏、最新评测、AI 推荐入口 ② 登录页 / ③ 注册页 /login.html · /register.html
账号密码 / 用户名邮箱登录，注册后不自动登录 ④ 游戏库列表页 /game-list.html
分类/热度/时间筛选、关键字搜索、分页卡片 ⑤ 游戏详情页 /game-detail.html?id=xx
封面信息、评分、收藏/游玩标记、评测列表、评论 ⑥ 个人中心 /my-profile.html
资料修改、改密、我的收藏、游玩档案、创作者申请 ⑦ 创作者工作台 /creator-work.html
文章列表、草稿管理、审核状态、作品数据统计 ⑧ 评测编辑页 /creator-edit.html?id=xx
富文本编辑器 + AI 创作助手对话框（大纲/润色/思路） ⑨-⑫ 管理员后台（4 页合一预览） /admin/*.html
仪表盘 / 用户管理 / 审核队列 / 游戏与分类管理
核心交互流
① 浏览流：首页 → 游戏库筛选/搜索 → 游戏详情 → 阅读评测 → 评论/点赞（未登录点收藏/评论 → 跳登录）
② 创作流：个人中心申请创作者 → 管理员审核通过 → 工作台新建评测 → AI 助手辅助写作 → 保存草稿/提交审核 → AI 自动审核（通过→发布 / 驳回→退回作者 / 存疑→人工复核）
③ 管理流：管理员仪表盘 → 处理创作者申请 → 审核队列人工决策 → 游戏库/分类/评论维护 → 查看 AI 审核日志
