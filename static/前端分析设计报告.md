# 前端分析设计报告（release 1.0.0）

> 项目：AI 游戏社区评测分享平台
> 阶段：阶段 3 — 前端项目生成与联调测试
> 技术栈：**方案 B — 原生 HTML + CSS + JavaScript**（PC 端）
> 测试方式：内置 Mock 数据层，后端未启动时可独立完成全流程测试；后端就绪后零改动切换

---

## 一、技术选型

| 项 | 选择 | 说明 |
|---|---|---|
| 页面 | 原生 HTML（12 个页面） | 无构建工具，浏览器直接运行 |
| 样式 | 原生 CSS（`css/style.css`） | CSS 变量主题、暗色游戏风格、Flex/Grid 布局 |
| 脚本 | 原生 JavaScript（ES6） | fetch + async/await，无第三方依赖 |
| 数据 | Mock 层（`js/mock.js`） | localStorage 持久化，刷新不丢数据 |
| 通信 | fetch 封装（`js/api.js`） | 自动携带 JWT、401 自动跳登录 |

### Mock / 真实后端无缝切换
`js/api.js` 启动时探测 `GET /api/health`：
- **可达** → 真实模式：所有请求发往 FastAPI 后端（`/api/...`），携带 `Authorization: Bearer <jwt>`；
- **不可达 / file:// 打开** → Mock 模式：请求路由到 `js/mock.js`，接口路径、请求体、响应结构与后端完全一致。

因此本套前端在后端开发完成后**无需改动任何业务代码**即可对接。

    ├── api.js            # 请求层：后端探测 / JWT 注入 / 401 处理 / 路由 Mock

## 四、Mock 数据设计（与后端表结构一一对应）

- **游戏数据均为真实存在的 Steam 游戏**（12 款）：艾尔登法环、博德之门 3、黑神话：悟空、赛博朋克 2077、荒野大镖客：救赎 2、巫师 3、反恐精英 2、哈迪斯、星露谷物语、文明 6、极限竞速：地平线 5、空洞骑士；含真实开发商、发行日期、分类与标签。封面图按各游戏美术风格生成。
- 种子账号：`admin/admin123`（管理员）、`creator/creator123`（创作者）、`player/player123`（玩家）。
- 种子覆盖全部业务状态：已发布评测、草稿、AI 驳回（广告引流，风险分 92）、人工复核（风险分 62）；评论含嵌套回复、点赞；收藏/游玩记录；2 条待审批创作者申请。

### AI 能力的 Mock 实现
- **AI 内容审核**（对应 DeepSeek）：提交审核时规则引擎扫描广告引流词（加群/微信/代购/链接等，→ 驳回，风险分 85+）、辱骂引战词（→ 人工复核，55+）、无命中（→ 自动通过发布，风险分 <10），并写入审核日志。
- **AI 游戏推荐**：结合用户收藏/游玩记录去重 + 偏好关键词加权排序，返回 3 款游戏及中文推荐理由。
- **AI 创作助手**：按动作（大纲/通关/润色/优缺点）或消息关键词返回结构化中文建议。

## 五、权限模型

| 能力 | 游客 | 玩家 | 创作者 | 管理员 |
|---|---|---|---|---|
| 浏览游戏/评测/评论 | ✅ | ✅ | ✅ | ✅ |
| 收藏/游玩标记/评论点赞 | ❌ | ✅ | ✅ | ✅ |
| AI 游戏推荐 | ❌ | ✅ | ✅ | ✅ |
| 申请创作者 | - | ✅ | - | - |
| 发文/AI 创作助手 | ❌ | ❌ | ✅ | ✅ |
| 用户/审核/游戏后台 | ❌ | ❌ | ❌ | ✅ |

前端路由守卫：未登录访问受保护页 → 跳登录并带 redirect；低角色访问高权限页（如玩家打开创作者中心）→ toast 提示并跳回。后端将再次做服务端鉴权（前端守卫仅体验层）。

| 玩家登录、首页 AI 推荐（输入偏好返回 3 款带理由） | ✅ |
| 游戏库分类筛选/关键字搜索/排序/重置/分页 | ✅ |
| 详情页收藏、游玩标记、评测展开、评论发表/回复/点赞、AI 相似推荐 | ✅ |
| 个人中心资料修改、收藏/游玩档案、创作者申请（重复提交拦截） | ✅ |
| 权限守卫：玩家访问创作者中心 → 403 提示跳回；创作者接口返回 403 | ✅ |
| 创作者工作台统计与五态文章列表、驳回原因展示 | ✅ |
| 富文本编辑、AI 助手大纲/优缺点回复、一键插入编辑器、保存草稿 | ✅ |
| 提交审核：正常内容 AI 自动通过并发布；广告内容 AI 驳回（风险分 95） | ✅ |
| 后台仪表盘统计、待办预览 | ✅ |
| 用户封禁/解封、授予创作者、创作者申请审批（自动升级角色） | ✅ |
| 人工复核通过、AI 审核日志（风险分颜色分级）、违规评论删除 | ✅ |
| 游戏编辑/新增/上架/下架（已下架可恢复）、分类新增/删除 | ✅ |
| 新用户注册 + 注册后登录 | ✅ |

测试中发现并修复的问题：
1. Mock 模式请求路径缺少 `/api` 前缀导致全接口 404（已修复）；
2. 后台游戏管理仅拉取上架游戏，下架后不可见不可恢复（新增管理员游戏列表接口，已修复）；
3. admin 子目录 401/登录回跳路径错误（已修复）；
4. 个人中心字母头像未放大（已修复）。
