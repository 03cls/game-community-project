AI ENGINE
AI 智能内核：三级降级
Ollama 本地模型优先 → DeepSeek 云端备选 → 规则引擎兜底
① Ollama 本地模型（优先）
模型：qwen2.5:3b · 端点：localhost:11434/api/chat
注入：平台数据快照 + 游戏库目录 + 对话历史
参数：temperature=0.6, num_predict=600
↓ 不可用时降级
② DeepSeek 云端 API（备选）
模型：deepseek-chat · JSON response format
触发条件：DEEPSEEK_API_KEY 非空
↓ 不可用时降级
③ 规则引擎（兜底，零 AI 也可用）
意图识别 + 关键词匹配 + 游戏知识库 + 数据库查询

AI DETAILS
AI 对话模块详解
三层架构 · 实时数据快照 · 游戏名四层匹配

🔧 架构

  • ▸ 前端：mock.js + 事件委托 data-qs/data-action + busy 防重复
  • ▸ 后端：ai_client.py（规则+Ollama+DeepSeek）
  • ▸ API：POST /api/ai/chat（匿名可用）
  • ▸ 4 个 Tab：推荐游戏 / 高分游戏 / 游戏百科 / 卡关
  • ▸ 标签轮换：data-qs="q1|q2|q3" 竖线分隔按序轮换
  • ▸ 创作者助手：快捷按钮 + 自由对话（需 creator 角色）

🧠 核心能力

  • ▸ 实时数据快照：_build_platform_digest(db) 聚合统计
  • ▸ 30 秒 TTL 缓存避免重复查聚合 SQL
  • ▸ 快照内容：游戏数/分类/用户/评测/社区/评分/Top5
  • ▸ 游戏名四层匹配：别名 → 中文全名 → 英文名 → 归一化
  • ▸ 推荐提取：从自然语言回复中提取游戏名 → 卡片
  • ▸ 强制规则：标签专题（巡礼/百科/榜单）强制规则引擎

📐 三栏布局

  • ▸ 中栏：meta-grid 信息、标签、描述展开/收起、Steam 购买按钮

  • ▸ score 为 int 1-10，重复提交 = 更新

  • ▸ 四维雷达仅从评测聚合（用户评分不影响四维）
  • ▸ 两个 keyword 过滤器（按游戏名 vs 按评测内容）

COMMUNITY
社区系统（UGC）
帖子 · 图片上传 · 楼中楼评论 · 频率限制

📢 帖子功能

  • ▸ 标题（2-100 字）+ 正文 + 图片（≤9 张，≤5MB/张）
  • ▸ 标签单选：游戏 / 闲聊 / 攻略 / 吐槽
  • ▸ 排序：推荐（热度）/ 最新 / 标签筛选
  • ▸ 频率限制：发帖 30s/次，评论 10s/次
  • ▸ 图片上传：FormData → /api/community/upload → static/uploads

💬 互动功能

  • ▸ 点赞、收藏、评论（楼中楼回复 parent_id）
  • ▸ 删除自己的帖子 / 评论
  • ▸ 我的收藏/点赞仅本人可见（他人 403）
  • ▸ 帖主可删除其下所有评论
  • ▸ 管理员可删除违规帖 + 封禁用户

COMMENTS
评论系统
统一模型 · 楼中楼回复 · 删除权限

💬 统一评论模型

  • ▸ Comment 表，target_type 区分：game（短评）/ review（评测评论）
  • ▸ parent_id 支持楼中楼嵌套回复

🎮 游戏短评特色

  • ▸ 分页：每页 5-10 条（page_size clamp 1-10）
  • ▸ 显示顺序：精选 → 普通分页（时间倒序）
  • ▸ 「我的评论」：GET /comments/mine 聚合两种类型
  • ▸ 点击跳转 #comment-{id} 锚点直达原文

UX
智能返回 & 多账号
三级返回策略 + 无缝账号切换

↩️ 智能返回 U.goBack()

  • ▸ 同标签页（history>1 且非弹出）→ history.back()
  • ▸ 新标签页（target=_blank，如管理员查看）→ document.referrer
  • ▸ 兜底 → fallback URL（如 game-list.html）
  • ▸ 覆盖 6 个页面：game-detail / review-detail / review-list / community-post / community-new / creator-edit

🔐 多账号登录

  • ▸ gc_accounts 存储已登录账号列表 [{token, user}]
  • ▸ setSession 自动去重（按 user.id）
  • ▸ 导航栏下拉展示全部账号，当前 ✓ 标记
  • ▸ 一键切换（switchAccount → reload）
  • ▸ 退出当前自动切到下一个
  • ▸ 401 自动移除失效账号 + 切换

ARCHITECTURE
技术架构
FastAPI + Ollama 本地模型 + 原生前端 · 单进程按需启动

🔧 技术栈

  • ▸ 后端：FastAPI ≥0.110 + SQLAlchemy ≥1.4 + SQLite
  • ▸ AI：Ollama qwen2.5:3b（本地）+ DeepSeek（备选）+ 规则引擎
  • ▸ 前端：原生 HTML/CSS/JS（无框架）+ 模块化
  • ▸ 认证：python-jose JWT + bcrypt
